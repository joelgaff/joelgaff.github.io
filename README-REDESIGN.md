# joelgaff.com redesign — drop-in files

Keeps Minima 2.5 as the base. Copy everything in this folder into the root of
joelgaff.github.io, preserving paths. Then:

1. Copy your signature to images/signature.png (included here).
2. In _config.yml, no changes are required. Optional: update the tagline to the
   new hire-me copy if you want it to match the mockup exactly.
3. Delete _layouts/home.html conflicts if you had customized it (this replaces it).
4. git add -A && git commit && git push. GitHub Pages rebuilds automatically.

## What each file does
- assets/main.scss — all visual changes: Archivo type, green #16694A accent,
  new header/footer/nav, numbered rows, banner, archive + post styles.
  Minima variables are set before the import, overrides after.
- _includes/head.html — adds the Archivo Google Font + favicon.
- _includes/header.html — name + avatar left, text nav right (Home, Writing,
  Work, /now, Hire, About). Highlights the current page.
- _includes/footer.html — one-line footer: name/location left, links right.
- _layouts/home.html — new homepage: hero, signature, Rails World banner,
  Current work, Recent writing (3 posts).
- _layouts/post.html — post page: back link, mono meta with tags, new type.
- writing.html — /writing/ archive, all posts grouped by year.
- work.md, now.md, hire.md, about.md — new pages.
- images/signature.png — your signature (also used on the homepage hero).

Permalinks are untouched (/blog/:title/ still works). The old paginated
homepage is replaced; /writing/ lists everything instead.

## Markdown endpoints (.md URLs)
Every post also ships as raw markdown: append .md to any post URL
(/blog/some-title.md). This is generated by _plugins/markdown_output.rb,
which requires building with GitHub Actions:

1. Copy .github/workflows/jekyll.yml (included) into the repo.
2. Repo Settings -> Pages -> Build and deployment -> Source: "GitHub Actions".
3. Push. The workflow builds with your Gemfile and deploys.

Posts also advertise the .md version via <link rel="alternate"
type="text/markdown"> so agents can discover it.
